# 活动监视器（Activity Monitor）

简体中文 | [English](README_EN.md)

活动监视器是一款 Android 应用，用来查看手机里正在运行的系统和用户应用，以及它们占用的 CPU、内存和设备温度。

日常使用 Android 设备时，偶尔会遇到手机发热、卡顿的问题。除了重启，几乎没什么好办法。部分手机可以临时开启几分钟“超级省电”，限制后台应用和服务后再关掉，但操作不直观，也不是每台设备都支持。

活动监视器可以看到谁在占 CPU、谁在吃内存、手机现在有多热，一目了然。找到问题应用后，也可以直接结束、冻结、禁用应用，还能发现一些在后台偷偷启动的应用。

## 主要功能

- 分别查看系统应用与服务、用户应用。
- 查看应用的 CPU、内存占用和运行状态。
- 查看电池温度等设备状态信息。
- 结束正在运行的应用。
- 点击三点菜单或长按应用，可以进行冻结、禁用或恢复操作。
- 支持中文和英文，以及跟随系统、浅色、深色三种页面模式。

> 结束系统应用可能导致系统不稳定、应用崩溃或数据丢失。除非明确知道后果，否则不建议操作系统应用。

## 为什么需要额外授权

Android 可不是一个愿意随便交出后台名单的系统。普通应用平时基本只能看到自己那一亩三分地，想看别的应用占了多少 CPU、吃了多少内存？抱歉，概不提供。想可靠地结束其他应用？通常也没这个权限。

所以，活动监视器需要借助一次 ADB 授权，把内置的特权服务“叫醒”。它以与 ADB 调试相同的身份工作，这样才能拿到完整数据，并执行结束应用等操作。

- 不需要 Root。
- 不需要一直连接电脑；完成授权后可以正常使用。

说直白点，不授权的话，这个应用几乎派不上什么用场：界面能打开，但 CPU、内存、温度等关键数据会大量缺失，结束其他应用也基本不灵，最后大概率只能看看应用列表。

## 如何完成授权

### 方式一：手机支持“无线调试”

适合 Android 11 及以上，且系统保留“无线调试”功能的设备。

> 注：开启步骤略微麻烦，但配置完成后，只要手机不重启就能一直使用。

1. 在手机设置中开启“开发者选项”和“无线调试”。
2. 打开活动监视器，点击右上角菜单中的“启动特权服务”。
3. 选择“无线配对（无电脑）”。
4. 按应用提示，在系统无线调试页面选择“使用配对码配对设备”。
5. 下拉通知栏，填写页面显示的配对端口和 6 位配对码。
6. 配对完成后等待应用启动特权服务。

部分厂商会在系统中移除“无线调试”。如果应用提示“此设备不支持无线调试”，请使用下面方式二。

### 方式二：通过电脑执行一次 ADB 命令（更适合开发者）

适合所有支持 USB 调试的设备，也适合没有无线调试功能的手机。

> 注：这种方式更适合开发者，或者手机确实没有无线调试功能时使用。

1. 在手机设置中开启“开发者选项”和“USB 调试”。
2. 用 USB 数据线连接电脑，并在手机上允许 USB 调试。
3. 在活动监视器中打开“启动特权服务”，点击“复制电脑命令”。
4. 将命令粘贴到电脑终端并执行。
5. 返回活动监视器，点击“重新检测”。

电脑需要提前安装 [Android SDK Platform Tools](https://developer.android.com/tools/releases/platform-tools)（其中包含 `adb`）。

## 使用说明

- 首次打开时，如果还没有启动特权服务，界面会显示功能受限提示。
- 下拉列表或点击标题栏的刷新按钮，可以更新应用状态。
- 点击应用右侧的“结束”按钮，可以结束对应应用。
- 点击用户应用右侧的三点按钮，或长按应用，可以选择冻结、禁用或恢复。
- 特权服务会在设备重启后失效，需要重新执行一次授权。
- 部分应用被结束后会被系统自动拉起，这属于 Android 系统的正常行为。

## 常见问题

### 为什么 CPU、内存或温度一直显示「—」？

十有八九是特权服务还在“睡觉”。按照上面的步骤完成一次授权，把它叫醒，再下拉刷新即可。

### 为什么结束应用没有效果？

没拿到权限时，系统对你的结束请求基本是“已读不回”，最多只允许普通应用尝试清理一下缓存的后台进程。真想让应用停下来，未授权时更靠谱的办法还是去应用详情页点击“强行停止”。

### 为什么每次重启后都要重新授权？

这锅得 Android 背。出于安全考虑，系统会在设备重启后关闭调试授权和无线调试连接，应用没办法绕过。

### 这个应用需要 Root 吗？

不需要。通过无线调试或电脑 ADB 授权就能使用完整功能；已经 Root 的设备也可以把 Root 权限当作补充方案。

### 应用会上传我的数据吗？

应用的数据读取和特权服务都在本机完成，不包含把设备数据上传到服务器的功能。

## 兼容性

- 最低支持 Android 11。
